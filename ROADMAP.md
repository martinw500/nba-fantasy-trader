# Roadmap

The open work, in the order to do it. **The pathway** is the one list; each item under it is a full brief (why, what's already there, what to build, how to check it), written so a session can pick it up cold and run the whole item without reading anything else first.

**Everything already built is in `docs/HISTORY.md`** (the roadmap as it stood on Nov 16, word for word, 410 KB). Don't load it whole: grep an item's ID (M21, B13, Q24, ...) when a brief here points at one. Checks of the numbers: `AUDIT.md`. AI GM notes (`data/notes.md`) are open bugs and asks from the chat: read the open ones before picking from the pathway (none open on Nov 20).

**How to run it:** top to bottom. *"Read ROADMAP.md and do Q29"*, or *"run the pathway"* to have Claude run the items back to back, each as its own agent at the item's effort, checking each before starting the next. When an item is done: tick it in the pathway, put a dated "Done" note with the numbers measured under its brief, update README / `docs/MODEL.md` / `docs/FILES.md` / `docs/COMMANDS.md` / the gm skill where they describe it, run `python test_model.py`, and restart the app in Martin's Terminal. When a brief's whole section is done and a few weeks old, move it to the end of `docs/HISTORY.md` so this file stays short.

**Effort (always Opus or better):** `xhigh` for engine maths, calibration and wrong-number bugs; `high` for features, fixes and parser work; `medium` only for really easy jobs (wording, docs, small UI tweaks). Items are big on purpose (Martin, Nov 16: "dont make roadmaps small i want them to be able to run a lot in one"): each is one session's worth of related work on the same code, so the session reads that code once.

**Rules every item keeps** (CLAUDE.md has the list): every number comes from `model.py`; a new number gets a `model.py` command (under ~30 KB of JSON), an `/api/` route, an AI GM tool line in the gm skill and a check in `test_model.py`; new stat tables honour punt dimming; no modals (DESIGN.md); nothing scheduled, nothing that messages Martin (Decisions 7: app only).
