# Commands: every backtest mode and every model.py command

What each `backtest.py` mode replays, which constants it fits and how long it takes, and `model.py`'s JSON commands with their flags. Moved here from CLAUDE.md on Nov 15, 2026, word for word. **Find the mode that covers a constant before changing it, and rerun it after.**

Python lives in `.venv` (Homebrew Python blocks global pip): use `.venv/bin/python` or `source .venv/bin/activate`.
- `python test_model.py`: self-check, synthetic data, no network. Run it after touching `model.py`.
- `python backtest.py`: calibration check (~1 min). Run it after changing projections or odds maths. `python backtest.py replay`: rest-of-season error by expert weight (fits `PROJ_W`). `python backtest.py teammates`: next week's error with teammates' injuries (fits `SHARE` / `USAGE`, ~3 min). `python backtest.py onoff [season]`: the same by `ONOFF_K` (each team's own split, ~5 min). `python backtest.py rates [season]`: the same split for production per minute by stat group (M22, Nov 3: no better on 2022-23 to 2025-26, not shipped; FG% splits don't repeat, ~4 min). `python backtest.py minor [season]`: the same with 15–25 min sitters handing out `SHARE_LOW` of their minutes (`REGULAR` 15) and the `CAP_GIVE` cap (M25, Nov 4: stats worse in 2025-26 and 2024-25, cap no change; both off, ~25 min). `python backtest.py bench`: rest-of-season error by `BENCH_MIN` for players no expert projects, 2022-23 to 2025-26 (M26, ~10 min). `python backtest.py rookies`: the same by a rookie's expert weight and rate shrink (fits `ROOKIE_W` / `ROOKIE_K`, audit #3, ~1 min). `python backtest.py yahoo`: this season's snapshots, each one's Yahoo lines vs each player's first-seen one, against the games after it (audit #2, Nov 4: the live line stays; rerun as snapshots pile up, seconds). `python backtest.py ahead`: from every day of the week, each game left for players who played their team's last game vs `fresh_plays()`, back-to-backs apart (M27, M28: fits `B2B`; ~1 min). `python backtest.py gameday`: how often listed players played (fits `GAMEDAY`, seconds). `python backtest.py corr`: how a week's category misses move together and matchup log loss / calibration by `WEEK_LOAD`, 2022-23 to 2025-26, both modes (M9, ~30 s). `python backtest.py league`: the real league end to end, each pre-tip snapshot's rest-of-week totals and category odds vs what the teams banked by the week's last snapshot (Nov 9, weeks 2–3: totals within 2% but FTM +5%, BLK −5%, TO +6%; misses 0.8–1.3 of the model's sd; log loss 0.377 vs 0.415 if calibrated; ~40 s, rerun as snapshots pile up). `python backtest.py lineups`: whose games count on a night the snapshot was pulled before tip-off, the per-game guess vs the snapshot's lineup against the next snapshot's totals, and This week's expected starts for that night (B8, ~25 s; rerun as snapshots pile up). `python backtest.py news`: how often a player who's playing is newly ruled out mid-week, and for how long (fits `HAZARD` / `ONE_GAME`, seconds). `python backtest.py availability`: each Monday's games-played guess vs the real share, 2022-23 to 2025-26 (fits `AVAIL_*`, and `STATUS_AVAIL` from players who sat their team's last game). `python backtest.py playoffs`: each Monday's playoff and title odds vs what happened, 60 leagues, average weeks then the real schedule (M2) (fits `SEASON_SD` / `WEEK_SD`, ~10 min). `python backtest.py recency`: rest-of-season error by minutes shrink and recent games' weight on 2022-23 to 2025-26 (fits `MIN_SHRINK` / `RECENT`, seconds). `python backtest.py season`: the season line's rest-of-season error by `MIN_SHRINK_SEASON` and `NET_SEASON`, known lifts on, 2022-23 to 2025-26 (A6/A7, ~1 min).
- `python app.py --no-browser`: run the app without opening a tab. `#view` and `?punt=FT%25,TOV` deep-link a view and build.
- `python model.py {team|trade|ideas|search|waivers|movers|roster|week|strategy|news|compare|schedule|move|sources} [--punt ...]`: prints JSON (`trade` / `search` take `--no-free` and `--their-free`, and `--healthy-fa` works on any command; `compare --players "A, B"`, Q3; `schedule` = the schedule planner, `League.planner()`, Q4; `move --add A --drop B [--day D]` = the add/drop evaluator, `League.add_drop()`, Q7; `sources` = when each cache was fetched, `freshness()`, Q9; `wants --team T` = what T wants from you, `League.wants()`, Q17; `lineup [--vs T] [--cats C]` = this week's start/sit for the most category wins (or just those categories), `League.start_sit()`, Q18; `search --goal title` = the finder ranked on your title odds, Q24; `note [--text T]` = write a note for Claude Code to `data/notes.md`, or list the open ones, no league loaded; `ahead --week N [--weeks M] [--add A] [--drop B]` = a later schedule week or several, `League.weeks_ahead()`, also `week --week N` / `move --week N`; `what [--player X --line/--pct/--min/--health/--until | --clear]` = set, clear or list what-ifs, `whatif()`). `strategy` (the punt planner) takes ~40s.
